## Protocolo con Claude Code

Al iniciar cualquier tarea compleja con CC, usa este prompt de apertura:

> "Antes de ejecutar, lee la tarea completa y dime:
> 1. Decisiones que necesitas de mi parte
> 2. Ambigüedades en los requisitos
> 3. Efectos colaterales que anticipas (QA, golden hash, otros archivos)
>
> Espera mis respuestas. Una vez que las tengas, ejecuta todo
> de corrido sin pausas hasta tener el commit pusheado y
> 103/103 confirmado."

Esto evita interrupciones en medio de la ejecución y permite
resolver todas las ambigüedades de un jalón antes de tocar archivos.
